戰士圖鑑（ 隻）

成本欄是這一階要花的金幣，總價值是從第一階升上來的累計。標「新」的單位 wiki 尚未收錄，資料取自 Steam 更新公告。點名稱可開官方頭像，方便對照截圖。

傭兵一覽（24 隻）

能力說明已對照到 v26.9 的更新公告。收入率 = 收入 ÷ 秘晶成本。坦克生成在怪群前方、近戰在怪群中、遠程在後方。

1–21 波怪物

血量、攻擊力每個版本都在微調，遊戲內輸入 -info 波次（例如 -info 13）可看當前數值。

攻擊類型 × 護甲類型 傷害倍率

傷害 = 攻擊力 × 倍率。綠色是克制、紅色是被克。遊戲內按 F11 也能叫出這張表。

對局復盤

目前支援 2v2 排位。官方只保留一年內的對局。

版本與資料可信度

  • 戰士屬性、成本取自 wiki；wiki 多數頁面停在 2022–2024 年，所以另外逐篇讀了 2024-01 到 2026-09 的 Steam 更新公告，補上 13 隻新單位、Fire Elemental 改成魔法攻擊等變動。
  • 公告裡的數值改動多是百分比微調，這裡只記會影響判斷的部分：屬性、能力機制、光環數值。
  • 派兵計算只算屬性相剋，沒有模擬單位能力、站位和血量。像 Fire Lord 的護盾、Head Chef 的吸血、範圍傷害單位，仍要搭配傭兵能力一起判斷。
  • 傭兵和怪物的平衡改動頻繁，精確數值以遊戲內 -info 為準。
  • 對局復盤的資料即時取自官方 API（經 Cloudflare Worker 轉送，API key 不放在頁面裡）；單位與波次賞金取自官方 API 的單位清單，改版後要重抓。
  • 共用陣容和派兵紀錄存在這個頁面的共用資料裡：有「參與者」以上權限的人可以新增和修改，「檢視者」只能看。分頁、本機草稿只存在你自己的瀏覽器。
